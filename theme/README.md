# تم رنگی Claude برای متاتریدر ۵

توکن‌های رنگی مشترک با تمپلیت چارت (`mql5/Premium_Candles*.tpl`)، اعمال‌شده روی
لایه‌هایی از رابط متاتریدر که قابل دست‌کاری‌اند.

## چه چیزی واقعاً قابل تم‌کردن است

| لایه | کنترلش با | وضعیت |
|---|---|---|
| **سطح چارت** (کندل، گرید، خطوط، پس‌زمینه) | `Premium_Candles.tpl` / `Premium_Candles_Light.tpl` | ✅ ۱۰۰٪ توکن Claude |
| **قاب پنجره، دیالوگ‌ها، منوها، اسکرول‌بار، تولتیپ، کنترل‌های استاندارد ویندوزی** | `HKCU\Control Panel\Colors` (این اسکریپت) | ✅ توکن Claude |
| **پنل‌های اختصاصی متاتریدر** (Market Watch، Navigator، Toolbox، تب چارت‌ها، تولبار) | تم داخلی خود متاتریدر (روشن/تیره‌ی MetaQuotes) که از کلید `AppsUseLightTheme` ویندوز پیروی می‌کند | ⚠️ فقط روشن/تیره؛ رنگ دلخواه نمی‌پذیرد |

متاکوتس API برای رنگ دلخواهِ پنل‌های خودش نمی‌دهد. کاری که این اسکریپت می‌کند:
مطمئن می‌شود پنل‌های متاتریدر روی حالت درست (تیره با چارت تیره، روشن با چارت روشن)
باشند، و هر چیزی که Wine رسم می‌کند دقیقاً با توکن‌های Claude رنگ می‌گیرد.

## استفاده

```bash
./theme/apply-theme.sh dark      # مشکی گرم Claude
./theme/apply-theme.sh light     # کاغذ کِرم Claude
./theme/apply-theme.sh revert    # برگرداندن به رنگ‌های Wine که بار اول بکاپ شد
```

بعد از اجرا: راست‌کلیک روی چارت → Templates → تمپلیت متناظر را انتخاب کن،
سپس **متاتریدر را کامل ببند و باز کن** (Wine این رنگ‌ها را فقط موقع استارت می‌خواند).

## فایل‌ها

- `claude-dark.reg` / `claude-light.reg` — اسکیم رنگ Wine + کلید dark-mode
- `_wine-colors-backup.reg` — مقادیر اصلی، برای `revert` (بار اول خودکار ساخته شد)
- `apply-theme.sh` — ایمپورت + راهنما
